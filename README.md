


# Project Title: Acquire Logos


## Description
Acquire Logos is a single webApplication that accepts data, processes it and retrieves information about the word search. Example if u search for the word Apple it request the data from the server. Which returns the processed data .

## Features of Aquire Logos

- Search bar => search words
- Display definitions
- Display synonyms


## Technologies used

- HTML $ CSS for structure and styling
- Figma For Design
- Javascript
